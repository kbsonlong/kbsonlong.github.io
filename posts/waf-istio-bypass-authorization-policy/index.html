Istio 旁路/镜像联动阻断方案（IngressGateway + AuthorizationPolicy + Redis）

背景

旁路/镜像模式通过检测组件识别恶意请求，阻断则在入口或服务侧生效。Istio 提供 AuthorizationPolicy，可在 IngressGateway 或服务级进行精细的访问控制。本方案以 IngressGateway 为阻断点，根据旁路检测写入的 Redis 黑名单，动态下发 DENY 策略，实现“旁路检测→网关阻断”。

架构

  • 旁路检测：镜像流量到检测组件，命中后写入 Redis（含 TTL）
  • 决策引擎：去重、白名单、TTL 管理，维护 waf:ban:ip 集合
  • 执行器：生成/更新 Istio AuthorizationPolicy（按 IP 拦截），由控制面分发到 IngressGateway
  • 观测：阻断率与误报率监测，定期调整

前置条件

  • 已部署 Istio（含 IngressGateway），Mesh 正常工作
  • 使用 Docker 运行第三方组件（如 Redis）
  • IngressGateway 能获取真实客户端 IP（确保 X-Forwarded-For/use_remote_address 配置合适）

2. 在 IngressGateway 上下发阻断策略

apiVersion: security.istio.io/v1
kind: AuthorizationPolicy
metadata:
  name: waf-ban-ips
  namespace: istio-system
spec:
  selector:
    matchLabels:
      istio: ingressgateway
  action: DENY
  rules:
    - from:
        - source:
            remoteIpBlocks: ["1.2.3.4/32", "5.6.7.8/32"]
      to:
        - operation:
            methods: ["GET", "POST", "PUT", "DELETE"]

说明：remoteIpBlocks 用于在网关按客户端源 IP 控制；若在服务侧阻断，可改用 source.ipBlocks（对 Pod/服务来路更有效）。

3. 控制器联动策略生成

  • 周期性读取 Redis 黑名单，过滤过期与白名单
  • 渲染为 remoteIpBlocks 列表，更新 AuthorizationPolicy
  • 小流量灰度：先只对部分域名/路径对应的 VirtualService 进行流量分配，再逐步扩大范围

4. 旁路检测写入 Redis（示例流程）

  • 镜像流量到检测组件（ModSecurity/Coraza/自研规则等）
  • 命中后 SADD waf:ban:ip <ip> 并设置 TTL：SETEX waf:ban:ttl:<ip> <seconds> 1
  • 达到阈值后才入黑名单，降低误报

灰度与回滚

  • 先仅检测：旁路检测运行但不下发 DENY
  • 小流量试点：对少量 IP 或单一域名启用阻断
  • TTL 自动解封：到期自动移除，避免长期误封
  • 快速回滚：保留上一版本 AuthorizationPolicy，必要时立即回退

验证

  • 从被封 IP 发起请求，期望返回 403/401（视网关配置而定）
  • 正常 IP 访问应不受影响

运维要点

  • 保持入口与旁路规则一致性，避免检测与执行“说法不一”
  • 白名单管理：监控/办公网、CDN 出口等
  • 分层处置：边缘限速/挑战，网关阻断，服务级细粒度策略

何时切换为拦截

  • 当攻击特征稳定、低误报且已在小流量验证通过
  • 采用短 TTL 与逐步扩域策略启用，保留回滚路径

apiVersion: v1
kind: ConfigMap
metadata:
  name: waf-detector-app
  namespace: waf-poc
data:
  app.py: |
    import os, re
    from flask import Flask, request
    import redis
    app = Flask(__name__)
    r = redis.Redis(host=os.getenv('REDIS_HOST','redis'), port=int(os.getenv('REDIS_PORT','6379')))
    patterns = [r"select .* from", r"union .* select", r"<script", r"\.\./", r"or 1=1"]
    def ip_from(req):
        xff = req.headers.get('X-Forwarded-For')
        if xff:
            return xff.split(',')[0].strip()
        return req.remote_addr
    @app.route('/', defaults={'path': ''}, methods=['GET','POST','PUT','DELETE','PATCH'])
    @app.route('/<path:path>', methods=['GET','POST','PUT','DELETE','PATCH'])
    def tap(path):
        body = request.get_data(as_text=True) or ''
        uri = request.full_path
        ip = ip_from(request) or ''
        text = (uri + '\n' + body).lower()
        hit = any(re.search(p, text) for p in patterns)
        if hit and ip:
            r.sadd('waf:ban:ip', ip)
            r.setex(f'waf:ban:ttl:{ip}', int(os.getenv('BAN_TTL','600')), '1')
        return ('OK', 200)
---

apiVersion: v1
kind: ConfigMap
metadata:
  name: waf-controller-istio
  namespace: waf-poc
data:
  controller.py: |
    import os, redis
    from kubernetes import client, config
    config.load_incluster_config()
    api = client.CustomObjectsApi()
    r = redis.Redis(host=os.getenv('REDIS_HOST','redis'), port=int(os.getenv('REDIS_PORT','6379')))
    ns = os.getenv('NS','istio-system')
    name = os.getenv('NAME','waf-ban-ips')
    selector = {"matchLabels": {"istio": "ingressgateway"}}
    ips = [i.decode() for i in r.smembers('waf:ban:ip')]
    blocks = [f"{i}/32" for i in ips if r.ttl(f'waf:ban:ttl:{i}') > 0]
    spec = {
      "selector": selector,
      "action": "DENY",
      "rules": [{"from": [{"source": {"remoteIpBlocks": blocks}}]}]
    }
    body = {"apiVersion": "security.istio.io/v1", "kind": "AuthorizationPolicy", "metadata": {"name": name, "namespace": ns}, "spec": spec}
    try:
      api.get_namespaced_custom_object("security.istio.io","v1",ns,"authorizationpolicies",name)
      api.patch_namespaced_custom_object("security.istio.io","v1",ns,"authorizationpolicies",name, body)
    except:
      api.create_namespaced_custom_object("security.istio.io","v1",ns,"authorizationpolicies", body)
---
apiVersion: v1

              name: waf-controller-istio
