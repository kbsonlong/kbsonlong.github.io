VictoriaLogs 分层存储（SSD 7d / HDD 180d / S3 归档）

目标

  • 0–7 天：NVMe/SSD 上的 VictoriaLogs 实例，保证实时写入与高速查询。
  • 7–180 天：HDD 上的 VictoriaLogs 实例，承载历史分区并可查询。
  • ＞180 天：按分区归档到 S3，按需拉起只读实例做查询。

部署 

1

docker compose up -d
  • SSD 实例监听 9428，数据卷 ./data/vl-ssd
  • HDD 实例监听 9438，数据卷 ./data/vl-hdd

每日迁移与归档脚本

vl-tiering.sh 会：

  • 对 NVMe 实例中 <= now-7d 的分区：snapshot → rsync 到 HDD → attach(HDD) → detach(SSD) → 删除 SSD 分区目录
  • 对 HDD 实例中 <= now-180d 的分区：snapshot → aws s3 sync 到 s3://<bucket>/<prefix>/<tenant>/<table>/<YYYY>/<MM>/<partition> → detach(HDD)

环境变量：

export SSD_ADDR=http://localhost:9428
export HDD_ADDR=http://localhost:9438
export SSD_DATA=./data/vl-ssd
export HDD_DATA=./data/vl-hdd
export S3_BUCKET=<your-bucket>
export S3_PREFIX=victorialogs
export TENANT=default
export TABLE=logs
export AWS_REGION=ap-southeast-1

执行：

1

bash vl-tiering.sh

Cron 示例（每天 01:00） 

1

0 1 * * * cd /path/to/victorialogs-tiering && AWS_REGION=ap-southeast-1 S3_BUCKET=<bucket> bash vl-tiering.sh >> tiering.log 2>&1

注意事项

  • 仅按分区名 YYYYMMDD 识别与迁移；确保 VictoriaLogs 使用按日分区策略。
  • snapshot 保证复制一致性；不要直接同步 active 分区。
  • HDD 实例保留期设为 187 天（含 7 天缓冲），超期自动删除。
  • S3 归档后可通过独立只读实例按需查询，避免影响生产热/暖实例。
