Pgpool-II 监控工具集

概述

本工具集提供了一套完整的解决方案，用于监控和管理 Pgpool-II 和 PostgreSQL 集群。它包括 Prometheus 配置、Grafana 仪表板、Docker Compose 部署文件以及详细的文档。

文件清单

配置文件

  • docker-compose-pgpool-monitoring.yml: Docker Compose 配置文件，用于部署完整的监控环境
  • prometheus-pgpool-config.yml: Prometheus 配置文件，用于从 Pgpool-II 收集指标
  • grafana-datasources.yml: Grafana 数据源配置，自动添加 Prometheus 和 Loki
  • grafana-dashboards.yml: Grafana 仪表板配置，自动加载 Pgpool-II 仪表板
  • pgpool-dashboard.json: Grafana 仪表板定义，用于可视化 Pgpool-II 指标
  • promtail-config.yml: Promtail 配置文件，用于收集 Pgpool-II 和 PostgreSQL 日志
  • pgpool.conf.sample: Pgpool-II 配置示例，包含监控和日志设置
  • pgpool_exporter.yml: Pgpool-II Prometheus 导出器配置文件

脚本文件

  • setup-pgpool-monitoring.sh: 快速部署脚本，自动设置监控环境
  • failover.sh: Pgpool-II 故障转移脚本示例

文档文件

  • pgpool-monitoring-setup.md: 详细的监控系统部署和配置指南
  • pgpool-log-analysis.md: Pgpool-II 日志解析和分析指南
  • pgpool-monitoring-guide.md: Pgpool-II 监控指南，包括日志解析和常见问题排查

快速开始

使用 Docker Compose 部署

  1. 确保已安装 Docker 和 Docker Compose
  2. 克隆或下载本工具集
  3. 执行部署脚本：
1
2

chmod +x setup-pgpool-monitoring.sh
./setup-pgpool-monitoring.sh
  1. 访问 Grafana：http://localhost:3000 (用户名: admin, 密码: admin)

手动部署

  1. 创建工作目录：
1
2

mkdir pgpool-monitoring
cd pgpool-monitoring
  1. 复制配置文件：
1
2
3
4
5
6

cp /path/to/docker-compose-pgpool-monitoring.yml ./docker-compose.yml
cp /path/to/prometheus-pgpool-config.yml ./
cp /path/to/grafana-datasources.yml ./
cp /path/to/grafana-dashboards.yml ./
cp /path/to/pgpool-dashboard.json ./
cp /path/to/promtail-config.yml ./
  1. 启动服务：
1

docker-compose up -d

监控内容

本工具集监控以下内容：

  • Pgpool-II 服务状态
  • 连接池统计信息
  • PostgreSQL 节点状态
  • 查询性能指标
  • 负载均衡统计信息
  • 复制延迟
  • 故障转移事件
  • 关键日志事件

自定义配置

添加更多 PostgreSQL 节点

修改 docker-compose-pgpool-monitoring.yml 文件，添加更多 PostgreSQL 节点和对应的导出器。

调整告警阈值

在 Grafana 仪表板中，可以根据需要调整各指标的告警阈值。

自定义日志收集

修改 promtail-config.yml 文件，添加更多日志源或调整日志标签。

故障排查

如果遇到问题，请参考 pgpool-log-analysis.md 文件，了解如何解析和分析 Pgpool-II 日志。

贡献

欢迎提交 Issue 和 Pull Request 来改进本工具集。
