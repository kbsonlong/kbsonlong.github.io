Nginx Lua JWT 认证系统

基于 OpenResty (Nginx + Lua) 和 JWT 的轻量级认证代理系统，为 Grafana 等后端服务提供统一的身份认证和访问控制。

🚀 特性

  • 轻量级认证: 基于 JWT 的无状态认证机制
  • 高性能: 使用 OpenResty 和 Lua 脚本，性能优异
  • 易于部署: Docker Compose 一键部署
  • 安全可靠: 支持 HTTPS、安全 Cookie、CSRF 防护
  • 灵活配置: 支持多种认证方式和权限控制
  • 生产就绪: 包含完整的监控、日志和健康检查

环境变量说明

变量名描述默认值必需
JWT_SECRETJWT 签名密钥-✅
JWT_EXPIRES_INJWT 过期时间(秒)3600❌

📚 扩展功能

集成外部认证

可以扩展 nginx/lua/login.lua 来集成：

  • LDAP 认证
  • OAuth 2.0 / OpenID Connect
  • SAML 认证
  • 数据库用户存储

添加更多服务

在 docker-compose.yml 中添加新服务，并在 Nginx 配置中添加相应的代理规则。

自定义权限控制

修改 nginx/lua/auth.lua 中的权限检查逻辑，实现基于角色的访问控制（RBAC）。
